# What is this

Starbie is a PCB board that does stuff when you click two buttons. You have to design the board, the wiring, and the code to make it do what you want.
More detailed instructions on the official guide, but this project is very beginner friendly and all software used are free. BTW if you are in the Half Life event, they give you grants to pay for your stuff
